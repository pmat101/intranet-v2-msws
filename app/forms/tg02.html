TECHNICAL GUIDELINES / TG02

Document Organisation and Unique Identifier

Guidelines for consistent document management, version tracking and efficient collaboration.

UID number of all documents has three parts: PCODE - document name - version number, separated by a hyphen.
01

PCODE

From WO List maintained by Ms Aarti.

02

Document Name

  • A — Form1/2/3/4 etc. for FORMS
  • B — PFR for Feasibility Reports
  • C — Application for Application Form (single file)
  • D — TOR/TOR compliance for TOR Letter and its compliance
  • E — EIA for EIA Report
  • F — Encl for any other annexures
  • G — Single file of EIA Document
  • H — Presentation Document
  • J — Any FAE Report
  • K — Other for any document type not covered
03

Version No. (s)

Based on stage:

  • Initial draft suffix is 00
  • PP reviewed and QA reviewed are 01 and 02 respectively
  • Uploaded copy suffix is 03
  • Submitted copy suffix is 04*
  • *04 version is same at PH and Online stage for EIA
  • Circulated copy will be 05
  • Any changes subsequent to the Presentation or suggested by EAC is 06 and if needed 07 too
EXAMPLE
PES/2020/01-G-02

Means: PCODE PES/2020/01 project, Single File EIA document of QA reviewed copy.
